# 阅读页面的设计质量

用于新建或美化书籍学习页。沿用“阅读书桌”的导航、搜索位置及状态契约，增强阅读质量；仅做覆盖审查时无需读取。

## 先作设计判断

开始实现前，在工作记录中用几句话说明：读者当前要理解什么、主要阅读路径、最重要的一个入口、内容密度及视觉重点。有现成页面时先看首页和一个长章节，再决定改动。默认方向是安静的编辑式阅读界面：纸色背景、深色正文、朱红强调、宋体标题、系统无衬线正文。用户提供的新品牌或风格优先。

从真实内容决定布局：正文用连续阅读栏；概念比较才并列；论证过程用编号和连线；原文引用保留出处；练习与正文有轻微底色区别。不要把每段正文装成卡片，也不要为填满首屏造统计、金句、封面或学习进度。

## 一套可落实的视觉语言

- **排版**：主要正文默认 16px，行高 1.9；解释正文不小于 14px，辅助信息通常 12–13px。标题约 30–40px / 22–26px / 16–18px，用字重与间距建立层级。中文标题使用本机宋体，正文使用系统中文字体，离线无需下载字体。
- **行宽**：长文容器约 46em（中文约 40–46 字），宽屏多余空间给边距或旁注，不把正文铺满屏幕。内容自然增高，不设整屏高度，不截断论证与出处。短小主标题可使用 `text-wrap:balance`，正文不强制居中。
- **间距与对齐**：沿用 4/8/12/16/24/32/48/64px 间距层级；章节标题、正文、分隔线和表单共享左边线。小节内紧、章节间松，避免每段都用同样大的间隔。顶部品牌、导航和内容工具条各自保持稳定。
- **配色**：用 CSS 变量维护纸面、正文、辅助字、分隔线、强调和选中底色。朱红用于当前章节、重点标记及少量操作；错误和成功另有语义。普通文字与实际背景对比度至少 4.5:1，大字至少 3:1，必要控件边界与焦点至少 3:1；不能用浅灰正文制造“高级感”。
- **组件**：页面主入口最多一个主按钮，次要入口用文字链接。搜索、折叠、输入框统一边框和小圆角。选中导航用背景、标记及 `aria-current` 同时表达；只有悬浮菜单等叠层才需要明显阴影。
- **图片与图解**：只有帮助理解时才用，并保留图注、来源、替代文字。没有获准封面时可用明确标为“阅读笔记”的文字书签，不能冒充原版封面。关系图必须匹配真实概念及方向，手机上仍可阅读。
- **反馈**：悬停、按下、键盘焦点、展开和空搜索都要有清晰状态。动效限于约 120–180ms 的颜色与边框反馈；遵守减少动态效果设置。正文不做入场隐藏、滚动劫持或循环装饰动画。

模板中的 `--reading-width`、`--text-size`、`--heading-size`、`--surface`、`--accent-soft` 与间距变量可适配具体书籍；沿用同一组变量，不逐页堆叠覆盖样式。更换颜色时重新检查对比度。

## 与 Taste Skill 的适配边界

参考源：<https://github.com/Leonxlnx/taste-skill>，核对版本为 tasteskill 2.5.0（2026-11-05）。采用其先定方向、统一系统、内容驱动视觉和实看截图的方法。此处为针对阅读场景编写的独立规则，不复制其代码或素材。

其商业网站专用的整屏区块、强制照片数量、禁止图片说明、随机配色、在线字体、WebGL 与品牌展示要求不用于本学习页；不能删出处、减少正文或联网加载资源来通过商业网站检查器。学习页以本技能的覆盖与浏览器验收为准，不宣称通过未运行或不适用的 Taste 检查器。

## 检查实际页面

使用环境允许的浏览器查看 1440、1024、768、390px 宽度；再抽查 320px 和 200% 缩放。至少看首页、最长章节、展开概念和搜索结果，记录截图路径及观察结果。

- 第一眼能找到当前章节、搜索和阅读入口；大标题不挤压内容，说明文字不会压过正文。
- 同层标题、正文与分隔线对齐；中文换行自然，没有窄到每行数个字的旁栏。
- 桌面正文行宽受控；手机正常单列，没有导航遮住正文或整页横向滚动。必要宽表格在自己的容器里滚动。
- 控件文本不会裁切，触控主目标至少 44px；键盘焦点可见，禁用、选中、空结果不只靠颜色区分。
- 长标题、长链接、真实章节、嵌套折叠与空状态均能阅读；没有靠隐藏内容掩盖溢出。
- 断网后关键内容与样式可用；有减少动态效果设置时内容保持可见。

发现问题后修复并重新查看受影响尺寸。记录“静态检查通过”“浏览器实测通过”“未验证”各自的范围；没有截图或真实交互证据时，不把主观设计判断写成视觉验收完成。
