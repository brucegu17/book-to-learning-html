# 默认界面：阅读书桌

采用用户在 2026-10-21 确认的《被讨厌的勇气》最终界面（已将搜索从左栏移到正文右上角）。这是本技能默认风格，用户的新要求可以覆盖它。随包资源不包含原书、个人笔记或该书的学习数据。

## 可复用资源

- `../assets/reading-desk.css`：以实际确认版为基础，v1.4 补充阅读排版与控件层级，包括页眉、目录、框架、正文、折叠条目、练习、来源及窄屏样式。优先复用；设计判断与验收见 [design-quality.md](design-quality.md)。
- `../assets/reading-desk.html`：可直接打开的中性界面骨架，附最小导航、搜索和折叠定位逻辑。示例文字只用于展示排版，不是某本书的导读。它不实现 PDF、笔记存储或导入导出，这些功能按任务接入。
- 新项目复制两文件，在骨架中接入书籍内容；单文件交付时将 CSS 内联进 `<style>`。现有项目只迁移必要的结构与样式，保持内容、控件 ID、记录存储键和数据格式。

| 接入标记 | 用途 |
|---|---|
| 唯一 `id` | 每个面板及独立检索条目的路由和锚点目标 |
| `.panel` | 可切换的阅读面板，自动索引标题和正文 |
| `data-page-title` | 面包屑、面板检索标题 |
| `data-search-title` | 面板内独立概念或小节的检索标题；其正文不再计入父条目 |

在内容装载后建立索引。“全书搜索”覆盖已接入的学习内容（章节标题、章节正文和独立概念），不是原书全文；原书全文检索需另行实现。骨架已有导航、搜索、折叠定位及移动目录，PDF、学习记录和导入导出按项目需要接入。

## 固定布局

```text
header.topbar
  .topbar-brand
    移动端目录开关
    a.brand：.brand-seal + .brand-copy（书名、阅读与实践）
  原书入口（有可用原书时才显示）
.shell                          ← 目录与正文的共同网格父容器
  aside.sidebar                 ← 只放导航、进度和记录操作
    阅读 / 章节 / 所需学习活动 / 来源
  main
    .content-toolbar
      .page-location            ← 左侧面包屑
      .searchbox                ← 右上角全书搜索
    .panel                      ← 当前阅读内容
```

顶部书名只出现一份品牌标识，侧栏不再重复书名、印章和搜索区域。页面正文中的书名可作为阅读首页标题。不要把搜索重新放回左栏，也不要用大块“清空搜索”按钮占据空间。

## 视觉规格

| 项目 | 默认值与用法 |
|---|---|
| 纸面 / 正文 / 次级字 | `#fbf9f5` / `#1d1b19` / `#655d55` |
| 强调 / 分隔 / 浅底 | `#ab3422` / `#e4dfd8` / `#f1eee8` |
| 标题字族 | 本机宋体优先：Songti SC、STSong；不依赖在线字体 |
| 正文与控件 | 本机系统中文无衬线；主要正文 16px，解释正文 14–15px，行高约 1.9 |
| 主标题 / 二级标题 | 约 30–40px / 22–26px；不用超大营销标题 |
| 品牌 | 32×35px 朱红细线印章，书名 17px，下方 10px 副标题；新书更换印章字，不固定“勇” |
| 页眉 / 侧栏 | 页眉 62px；侧栏 232px，较窄桌面 210px |
| 搜索 | 右上角约 260×44px；细边框、放大镜、内置清空图标 |
| 内容形态 | 正文行宽约 46em；细线分隔、紧凑列表、小范围浅底提示；少用大圆角、重阴影和卡片墙 |

长书名通过 `min-width:0` 收缩并以省略号截断；更换书名时同步更新 `.brand` 的 `aria-label`，保留完整书名。菜单和原书按钮保留空间，不通过放大页眉解决。响应式基础值以随包 CSS 为准，可为具体书名和真实内容长度微调。

## 阅读层级

- 首页呈现书名、核心问题和阅读入口，保持克制；不堆叠统计数字或虚构阅读成果。
- 全局页先显示主线与关键关系；核心概念按章节或语义单元分组，详情和关系依据按需展开。循环、对照、条件关系保留本来形态。
- 章节正文保留问题、论证或叙事、异议与来源；原书小节可用折叠列表，练习放在阅读内容之后。
- 实践与误读采用紧凑折叠条目。没有相应内容的书不生成空模块，也不为了沿用样式强加实践卡。
- 小说沿用页面外框与视觉，正文模块改为情节、人物、冲突和主题；工具书、理论书等按各自阅读任务组织。

## 交互与窄屏约束

- 保留全局 `[hidden]{display:none!important}`，避免按钮的 `display:inline-flex` 让空搜索清空键、隐藏反馈或错题空态意外显示。
- 空搜索不显示清空键；有内容时才显示。清空后恢复搜索前章节，不承诺恢复精确滚动位置。搜索条目和深层链接须展开目标的所有祖先 `<details>`，不能只打开最近一层。
- 搜索在正文区域，输入时不得自动打开移动端侧栏。结果文本通过 `textContent` 等安全方式插入。
- 760px 及以下侧栏由顶部目录开关控制；面包屑在上，搜索占下一行。目录状态同步 `aria-expanded`，Escape 可收起；跨越断点时清理 `nav-open` 并同步关闭状态。
- 窄屏使用同一套 DOM 与唯一控件 ID，不复制第二份搜索框。章节与正文始终允许收缩，检查长中文和较长出处链接。
- 记录存储按书籍和版本隔离；视觉更新不更换旧书的存储键。不把示例用户记录写入模板。

## 使用 Stitch 时的边界

这套样式来自一次实际 Stitch 设计及用户后续修订，以随包最终 CSS 和布局为准。复用不需要重新调用 Stitch。用户要求新的视觉方向时，再按可用 Stitch 能力设计。保留真实生成与导出证据，不把“沿用设计”称作“本次重新生成”。

Stitch 中的样例作者名、页码、统计和进度不能当原书事实，实际页面均从已核对的书籍底稿生成。设计参考截图和本地成品运行截图分别标注；模板复用或静态检查通过不等于浏览器验收通过。
